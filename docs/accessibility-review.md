# مراجعة إمكانية الوصول

## إصلاحات منفذة

- رابط تجاوز إلى المحتوى.
- live region للشاشة ونتائج البحث والتنبيهات.
- Progressbar بأدوار وقيم ARIA.
- Label فعلي لحقل البحث وتعليمات خصوصية مرتبطة به.
- إدارة التركيز عند تغير السؤال أو النتيجة.
- حد أدنى 44px للأهداف اللمسية.
- دعم prefers-reduced-motion وprefers-contrast.
- focus-visible للملخص القابل للفتح.

## يحتاج اختبارًا بشريًا

- VoiceOver على iPhone/Safari.
- تكبير 200% و400%.
- اختبار مستخدم كفيف أو ضعيف بصر.
- مراجعة تباين آلية بالأداة المعتمدة على جميع الحالات.
