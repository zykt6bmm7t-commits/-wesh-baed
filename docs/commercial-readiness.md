# الجاهزية التجارية

## الحالة

NO-GO للبيع العام حتى إكمال بوابات الاعتماد البشري أدناه. النسخة الحالية مناسبة للاختبار الداخلي فقط، وليست معتمدة قانونيًا أو ضريبيًا.

## يلزم قبل البيع العام

1. اعتماد المحتوى بواسطة محامٍ سعودي مرخص.
2. شروط استخدام وإخلاء مسؤولية وسياسة استرجاع وترخيص شخصي يعتمدها محامي تجارة إلكترونية.
3. حسم صفة البائع والمنشأة والفوترة وضريبة القيمة المضافة مع محاسب/مستشار ضريبي.
4. عدم استخدام عبارات: «استشارة قانونية»، «نتيجة مضمونة»، «معتمد من وزارة العدل»، أو «بديل عن المحامي».
5. وصف مقترح: «دليل إجرائي تفاعلي يساعدك على تحديد المسار الأقرب والرجوع إلى المصدر الرسمي».

## نموذج البيع المبدئي

- نسخة أفراد: شراء مرة واحدة مع مدة تحديث معلنة.
- النسخة المهنية أو الاشتراك: تؤجل حتى وجود آلية تحديث ومراجعة بشرية دورية واتفاقية ترخيص منفصلة.
