# ترخيص الاستخدام الشخصي

> **DRAFT — REQUIRES PROFESSIONAL APPROVAL**

يمنح المشتري، بعد سداد المقابل، ترخيصًا محدودًا وغير حصري وغير قابل للتحويل لاستخدام نسخة «وش بعد؟» لأغراضه الشخصية فقط، وفق شروط البيع المعتمدة.

لا يشمل الترخيص:

- إعادة البيع أو التأجير أو منح نسخ للغير.
- النشر العام أو التجاري أو رفع الملف في منصات مشاركة.
- استخراج قاعدة البيانات أو نسخها أو تحويلها إلى منتج منافس.
- إزالة إشعارات الحقوق أو نسب العمل إلى غير صاحبه.

لا يمنع هذا الترخيص ما يسمح به النظام صراحة، ولا يدعي ملكية النصوص النظامية أو المواد والمصادر الحكومية. مدة الترخيص، عدد الأجهزة، التحديثات، النسخ الاحتياطية، وآلية الإنهاء: **[يعتمدها المحامي وفق نموذج البيع.]**
