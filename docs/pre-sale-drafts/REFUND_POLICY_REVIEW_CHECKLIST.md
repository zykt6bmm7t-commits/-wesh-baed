# قائمة مراجعة سياسة الاسترجاع والاسترداد

> **DRAFT — REQUIRES PROFESSIONAL APPROVAL**

هذه قائمة أسئلة تشغيلية وليست سياسة منشورة.

- [ ] تحديد صفة البائع وبيانات المنشأة. **[PROFESSIONAL REVIEW REQUIRED — LEGAL/TAX]**
- [ ] تحديد نموذج البيع: ملف رقمي، وصول ويب، اشتراك، أو مزيج. **[PROFESSIONAL REVIEW REQUIRED]**
- [ ] تحديد اللحظة التي يعد فيها المنتج مسلّمًا أو مستخدمًا. **[PROFESSIONAL REVIEW REQUIRED — LEGAL]**
- [ ] تحديد الحالات التي يلزم فيها الإصلاح أو الاستبدال أو الاسترداد. **[PROFESSIONAL REVIEW REQUIRED — LEGAL]**
- [ ] حسم حكم الرجوع في المنتج الرقمي وشروط الإفصاح والموافقة قبل الدفع. **[PROFESSIONAL REVIEW REQUIRED — LEGAL]**
- [ ] تحديد مهلة طلب الاسترداد وقناة الطلب ومدة الرد. **[PROFESSIONAL REVIEW REQUIRED — LEGAL/OPERATIONS]**
- [ ] تحديد طريقة إعادة المبلغ ومعالجة رسوم بوابة الدفع. **[PROFESSIONAL REVIEW REQUIRED — TAX/ACCOUNTING]**
- [ ] معالجة الشراء المكرر، العملية غير المصرح بها، والملف أو الرابط غير العامل. **[PROFESSIONAL REVIEW REQUIRED]**
- [ ] بيان أثر الخصومات والقسائم والباقات والاشتراكات. **[PROFESSIONAL REVIEW REQUIRED — LEGAL/TAX]**
- [ ] مطابقة السياسة مع شروط المتجر ومزود الدفع والفاتورة. **[PROFESSIONAL REVIEW REQUIRED — LEGAL/TAX]**
- [ ] عرض السياسة قبل الدفع وحفظ ما يثبت قبولها. **[PROFESSIONAL REVIEW REQUIRED — LEGAL]**

لا تتحول هذه القائمة إلى سياسة نافذة إلا بعد استكمال نموذج البيع واعتماد المختصين.
