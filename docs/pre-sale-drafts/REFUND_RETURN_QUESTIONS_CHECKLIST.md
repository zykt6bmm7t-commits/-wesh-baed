# قائمة أسئلة سياسة الاسترجاع والاسترداد

> **DRAFT — REQUIRES PROFESSIONAL APPROVAL**

- [ ] ما صفة البائع وبياناته النظامية؟
- [ ] هل البيع ملف رقمي، وصول ويب، اشتراك، أم مزيج؟
- [ ] متى يعد المنتج مسلّمًا أو مستخدمًا؟
- [ ] هل توجد نسخة تجريبية أو معاينة قبل الدفع؟
- [ ] ما الحالات التي يجب فيها الإصلاح أو الاستبدال أو الاسترداد؟
- [ ] كيف تعالج الملفات التالفة أو الرابط غير العامل أو تعذر الوصول؟
- [ ] هل يسمح النظام باستثناء المنتج الرقمي من الرجوع في الحالة المختارة، وما شروط الإفصاح والموافقة؟
- [ ] ما مدة تقديم الطلب والمستندات المطلوبة؟
- [ ] ما قناة الطلب ومدة الرد؟
- [ ] كيف يعاد المبلغ، ومن يتحمل رسوم بوابة الدفع؟
- [ ] كيف تعالج عمليات الشراء المكررة أو غير المصرح بها؟
- [ ] كيف تؤثر الخصومات والقسائم والباقات والاشتراكات؟
- [ ] ما آلية الشكاوى والتصعيد؟
- [ ] هل تتطابق السياسة مع شروط المتجر ومزود الدفع؟
- [ ] هل صيغت السياسة بلغة واضحة وعرضت قبل الدفع مع إثبات القبول؟

لا تنشر إجابات هذه القائمة كسياسة نهائية قبل اعتماد محامي التجارة الإلكترونية ومراجعة نموذج البيع الفعلي.
