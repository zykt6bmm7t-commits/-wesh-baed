# مراجعة الخصوصية والأمن

## ما يجمعه الإصدار الحالي

- لا توجد حسابات مستخدمين أو نماذج ترسل الحالة إلى خادم المشروع.
- لا توجد Cookies أو أدوات Analytics داخل الملف الحالي.
- يُحفظ محليًا فقط معرّف السؤال/النتيجة الحالية ومسار الرجوع في localStorage بالمفتاحين `wb_current` و`wb_history`.
- البحث يعمل محليًا داخل المتصفح.
- فتح المصدر الرسمي ينقل المستخدم إلى جهة خارجية تطبق سياستها المستقلة.

## ضوابط منفذة

- تنبيه المستخدم لعدم كتابة الاسم أو الهوية أو البيانات الشخصية في البحث.
- تقليل البيانات إلى حالة تنقل غير معرفّة مباشرة.
- إمكانية حذف الحالة المحلية عند البدء من جديد.
- الروابط الخارجية تستخدم `noopener`.

## قبل إضافة حسابات أو تحليلات أو دفع

يلزم تقييم نظام حماية البيانات الشخصية، تحديد المسوغ والغرض والاحتفاظ والحذف والأطراف الثالثة، وإجراء مراجعة أمنية واختبار اختراق مناسب. لا يدّعي المشروع امتثالًا كاملًا لـPDPL.
